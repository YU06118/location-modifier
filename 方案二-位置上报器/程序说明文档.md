# 位置上报器 · 程序说明文档

面向开发者：结构、实现、打包、验证。使用者请看《使用文档.md》。

## 1. 文件结构

```
方案二-位置上报器/
├── core.py              核心逻辑（CLI + CDP 客户端 + 供 GUI 复用的函数）
├── gui.py               customtkinter 图形界面
├── dist/位置上报器.exe    单文件可执行程序
├── 使用文档.md
└── 程序说明文档.md        本文档
```

运行时在同目录生成 `.location_sessions.json`（活跃注入会话记录，供清理用）。

## 2. 分层设计

| 层 | 位置 | 职责 |
|---|---|---|
| 坐标层 | `wgs84_to_gcj02` 等 | 坐标系转换（境外直通） |
| 传输层 | `MiniWebSocket` | 标准库实现的最小 WebSocket 客户端 |
| 协议层 | `CDPClient` | CDP 消息编号、发送、响应匹配 |
| 发现层 | `scan_pages/http_json` | 扫描调试端口上的页面 |
| 会话层 | `write_session/clear_sessions_file` | 记录活跃注入 |
| CLI 层 | `cmd_*` | 命令行入口（保留） |
| GUI 层 | `gui.py` `App` | 窗口界面，调用 core |

## 3. 关键实现

### 3.1 路径处理（打包关键）

`SESSION_FILE` 用 `_app_dir()` 判断 `sys.frozen`：打包后落盘到 exe 同目录，源码运行时用脚本目录。避免 onefile 临时目录导致会话记录丢失。

### 3.2 零依赖 WebSocket 客户端

环境中 `websocket` 是空命名空间包（`__file__` 为 None），`import` 成功但无 `create_connection`。因此自实现：

- 握手：TCP 连接 → HTTP GET + `Sec-WebSocket-Key`（base64 随机 16 字节）→ 等 `101`
- 发送：帧头 `0x81` + 长度（<126 直接 / <65536 `!H` / 否则 `!Q`）+ 4 字节掩码 + 掩码载荷
- 接收：处理 126/127 扩展长度；opcode `0x1` 文本、`0x9` ping 回 pong、`0x8` close

### 3.3 CDP 注入与会话保持

```python
client.call("Emulation.setGeolocationOverride", {
    "latitude": lat, "longitude": lon, "accuracy": 20})
```

覆盖绑定 WebSocket 会话，**断连即失效**。GUI 用后台线程保持连接，`stop_event` 控制停止；停止时先 `clearGeolocationOverride` 再关闭连接。窗口关闭事件 `on_close` 也调用停止逻辑，避免遗留注入。

### 3.4 权限尽力授权

注入前取浏览器级 WebSocket（`/json/version`），对页面 origin 调 `Browser.grantPermissions`。失败不阻断注入，仅在状态提示中说明 HTTPS/权限前提。

### 3.5 坐标系

高德/百度用 GCJ-02，CDP 按 WGS-84 语义，中国境内差约 500 米。`wgs84_to_gcj02` 用标准经验公式；境外直通。GCJ→WGS 用 4 次迭代逼近可达 0 误差。

### 3.6 GUI 线程模型

扫描浏览器、注入保活都在后台线程；通过 `after(0, callback)` 回主线程更新控件。`_toggle_inject` 用 `self.injecting` 状态切换按钮文案与颜色（注入中显示红色「停止注入」）。

## 6. 已知限制

- 只对注入的浏览器页面生效，不影响系统其他程序。
- 目标页需 HTTPS/localhost 且允许定位权限；权限错误是页面策略，非注入失败。
- 连接断开即恢复真实位置，这是 CDP 机制。
