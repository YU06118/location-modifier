# 位置上报器 · 使用文档

## 一、这是什么

一个带窗口的桌面程序，让浏览器页面**读到指定的经纬度坐标**。用于地图类网页、位置相关功能的开发调试。

**它不改变网络出口 IP**。网站若用 IP 库反查，仍能看到你的真实地区。它改的只是应用通过定位接口读到的坐标值。

## 二、运行

进入本文件夹，双击 `dist/位置上报器.exe`。无需安装 Python。

## 三、首次准备：启动浏览器调试端口

程序需要连接一个以调试端口启动的 Chrome / Edge。

1. **完全关闭**已有的 Chrome / Edge（否则新参数不生效）。
2. 在命令行执行：

**Windows（Edge 示例）**：
```
"C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe" --remote-debugging-port=9222
```

**macOS（Chrome 示例）**：
```
/Applications/Google\ Chrome.app/Contents/MacOS/Google\ Chrome --remote-debugging-port=9222
```

建议加 `--user-data-dir=<一个空目录>` 用独立配置启动，不影响日常浏览器。

## 四、界面说明

- **左侧「快捷城市」**：16 个内置城市，点「填入」即把坐标填到右侧。
- **右侧「坐标与目标页面」**：经纬度输入框、可注入页面列表、注入状态、开始/停止按钮。
- **底部**：状态提示 + 重新扫描按钮。

## 五、操作步骤

### 第 1 步：选坐标

两种方式任选：

- 点左侧某个城市的「填入」
- 或在右侧手动输入纬度、经度（南纬/西经用负数）

### 第 2 步：确认浏览器页面

程序启动时会自动扫描。若列表为空，点底部「重新扫描浏览器」。列表会显示每个页面的端口、标题、地址。

### 第 3 步：开始注入

点「开始注入」。按钮变为「停止注入」，状态显示"注入中"。程序保持与浏览器的连接——**连接一断，注入自动失效**，这是 CDP 的机制。

### 第 4 步：验证

在目标网页调用定位功能（如地图定位），读取到的坐标应为刚才设置的值。

### 第 5 步：停止

点「停止注入」，或直接关闭程序窗口。位置恢复真实值。

## 六、关键前提（否则读不到坐标）

- 目标页面必须是 **HTTPS 或 localhost**（浏览器定位接口的安全要求）。
- 页面需**允许定位权限**。程序会尽力自动授权，但策略严格时仍需手动允许。
- 若网页报定位权限错误，说明是页面授权问题——**注入本身已成功**，检查上述两项即可。

## 七、常见问题

| 现象 | 处理 |
|---|---|
| 扫描不到页面 | 浏览器没以 `--remote-debugging-port=9222` 启动，或没完全关闭旧实例 |
| 页面位置没变 | 页面非 HTTPS / 未授权 / 未刷新；检查前提 |
| 关闭程序后位置恢复 | 正常，CDP 注入随连接断开失效 |
| 想保持位置 | 保持程序运行，不要关闭 |

## 八、合规

仅用于位置功能调试等合法场景。不要用于伪造打卡、虚假定位或欺诈。
