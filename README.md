# 位置修改器

两套独立的桌面程序，各自解决"让电脑显示为其他地区"这件容易混淆的事。均为**带窗口的 exe**，双击即用，无需安装 Python。

> 仅用于开发测试、合规远程办公、位置功能调试等合法场景。请勿用于伪造打卡、欺诈、绕过风控或未授权跨境访问。

## 先选对工具

| 你的目标 | 用哪个 exe |
|---|---|
| 让网站以为我在另一个地区访问 | **出口IP换向器**（改网络出口公网 IP） |
| 让某个网页读到另一个经纬度 | **位置上报器**（改定位接口返回值） |
| 改本机 192.168.x.x 地址 | 都不用（那不改公网归属地） |

一句话：**骗过网站 → 方案一；调试地图坐标 → 方案二。**

## 方案一：出口 IP 换向器

- 窗口内管理代理节点、一键切换出口、一键恢复直连
- 实时显示系统代理状态、出口 IP、归属地
- 支持 HTTP / SOCKS5，Windows 与 macOS
- **需自备合法代理节点**，程序不提供

## 方案二：位置上报器

- 16 个快捷城市 + 手动经纬度输入
- 扫描浏览器页面，一键注入 / 停止
- 零第三方依赖（标准库自实现 WebSocket）
- **需以 `--remote-debugging-port=9222` 启动浏览器**；目标页须 HTTPS/localhost 且允许定位

## 验证状态

| 项 | 方案一 | 方案二 |
|---|---|---|
| 核心自检 | 11/11 | 8/8 |
| GUI 实例化 | 通过 | 通过（16 城市、坐标回填） |

## 运行环境

Windows 10/11 或 macOS。源码如需修改，用 Python 3.15 + customtkinter；运行 exe 不需要任何环境。
