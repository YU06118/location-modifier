# 出口 IP 换向器 · 使用文档

## 一、这是什么

一个带窗口的桌面程序，用来切换电脑的**网络出口**。切换后，外部网站看到的公网 IP 会变成你所选节点所在地区的 IP。

**重要**：本程序**不提供代理节点**。你需要有自己合法可用的代理服务（公司/校园合规代理、自建代理等），程序只负责配置和切换。

## 二、运行

进入本文件夹，双击 `dist/出口IP换向器.exe`。

无需安装 Python，无需联网安装依赖。首次启动约 1–3 秒（onefile 解包）。若 Windows 弹出安全提示，选「更多信息 → 仍要运行」。

## 三、界面说明

程序分为三块：

- **左侧「节点列表」**：显示已添加的代理节点，当前生效的标为 `●`。
- **左侧表单**：添加新节点（名称、地区、协议、端口、主机）。
- **右侧「当前出口状态」**：显示系统代理开关、代理地址、出口 IP、归属地。
- **底部**：状态提示 + 「查询当前出口」按钮。

## 四、操作步骤

### 第 1 步：添加节点

在左侧表单填写：

| 字段 | 填什么 |
|---|---|
| 名称 | 自己起的名字，如「上海节点」 |
| 地区 | 备注用，如「上海」 |
| 协议 | `http` 或 `socks5`，按你的代理服务选 |
| 端口 | 数字，如 `8080` |
| 主机 | 代理服务器的 IP 或域名 |

点「添加节点」。节点会出现在上方列表。

### 第 2 步：选中节点

在列表中点该节点的「选择」按钮。底部状态栏会提示已选中。

### 第 3 步：切换出口

点右侧「切换到选中节点」。程序会：

1. 自动备份你原来的系统代理设置（仅首次）
2. 写入新代理并通知系统立即生效
3. 查询并显示新的出口 IP 与归属地

### 第 4 步：恢复直连

点「恢复直连」。程序会按备份**精确还原**原始设置，不是简单关掉。

## 五、常见问题

| 现象 | 处理 |
|---|---|
| 出口 IP 查询失败 | 稍后点「查询当前出口」重试；程序内置多个查询服务 |
| 切换后部分网站打不开 | 节点不稳定或协议选错；换节点或用 socks5 |
| 想确认是否生效 | 看右侧「归属地」是否变成节点所在地 |
| 节点填错了 | 直接再加一个正确的节点，选中后切换 |
| 关不掉代理 | 点「恢复直连」；它按备份还原 |

## 六、注意事项

- `use` / 切换是**真实改写系统代理**的操作，请勿在不确定节点可用性时执行。
- 程序已把 `localhost`、`127.0.0.1`、`*.local` 设为代理例外，不影响本机服务。
- 配置文件 `proxy_nodes.json` 保存在 exe 同目录，可备份；换机器时拷过去即可。
- 仅用于合法场景。不要用于未授权跨境访问、伪造打卡或绕过风控。
