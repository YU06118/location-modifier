# 出口 IP 换向器 · 程序说明文档

面向开发者：结构、实现、打包、验证。使用者请看《使用文档.md》。

## 1. 文件结构

```
方案一-出口IP换向器/
├── core.py              核心逻辑（CLI + 可被 GUI 复用的函数）
├── gui.py               customtkinter 图形界面
├── dist/出口IP换向器.exe  单文件可执行程序
├── 使用文档.md
└── 程序说明文档.md        本文档
```

运行时在同目录生成 `proxy_nodes.json`（节点配置 + 当前节点 + 原始设置备份）。

## 2. 分层设计

| 层 | 位置 | 职责 |
|---|---|---|
| 配置层 | `core.py` `load_config/save_config/find_node` | 读写 JSON 配置 |
| 格式层 | `build_windows_proxy_string/build_mac_proxy_args/build_proxy_url` | 各平台代理格式（纯函数，可测） |
| 系统层 | `win_read_state/win_write_state/win_notify/mac_set_proxy/mac_clear_proxy` | 平台相关系统代理读写 |
| 验证层 | `query_exit_ip/parse_ip_response` | 查询并解析出口 IP 归属地 |
| CLI 层 | `cmd_*` | 命令行入口（保留，便于脚本调用） |
| GUI 层 | `gui.py` `App` | 窗口界面，调用上述函数 |

GUI 不重复实现业务逻辑，直接复用 core 的函数——这是为了保证 CLI 与 GUI 行为一致。

## 3. 关键实现

### 3.1 路径处理（打包关键）

```python
def _app_dir():
    if getattr(sys, "frozen", False):
        return os.path.dirname(os.path.abspath(sys.executable))  # exe 同目录
    return os.path.dirname(os.path.abspath(__file__))            # 源码目录

CONFIG_PATH = os.path.join(_app_dir(), "proxy_nodes.json")
```

**为什么必须这样**：onefile 打包后 `__file__` 指向临时解压目录，若用它定位配置，每次运行配置都会丢失。这是一个只有打包后才暴露的 bug，已在本次修正。

### 3.2 Windows 系统代理

写注册表后必须通知系统，否则要重启才生效：

```python
winreg.SetValueEx(key, "ProxyEnable", 0, winreg.REG_DWORD, 1)
winreg.SetValueEx(key, "ProxyServer", 0, winreg.REG_SZ, "http=h:8080;https=h:8080")
ctypes.windll.Wininet.InternetSetOptionW(0, 39, 0, 0)  # SETTINGS_CHANGED
ctypes.windll.Wininet.InternetSetOptionW(0, 37, 0, 0)  # REFRESH
```

格式：HTTP 节点 `http=host:port;https=host:port`；SOCKS 节点 `socks=host:port`。

### 3.3 备份与还原

首次切换前把 `win_read_state()` 的三元组（ProxyEnable / ProxyServer / ProxyOverride）存进配置；`off` 时原样写回。这样用户原本设过代理或例外也能正确恢复。

### 3.4 出口 IP 查询

- 国内服务优先（myip.ipip.net、ip.zxinc.org），国际服务在国内常 429/超时。
- 用 `ProxyHandler({})` 绕过系统代理，避免"用代理查代理自己"。
- `parse_ip_response` 兼容三种返回格式，其中 zxinc 的 `data.ip` 是 dict，需先判类型再取 `myip` 或嵌套 `query`——曾因直接 `.strip()` dict 导致崩溃，已修复。

### 3.5 GUI 线程模型

查询出口 IP、切换代理、恢复直连都在 `threading.Thread` 中执行，通过 `after(0, callback)` 回主线程更新控件，避免网络等待卡住界面。按钮在忙时置 disabled，防止重复点击。

## 4. 打包

```bash
py -3.15 -m PyInstaller --noconfirm --clean --onefile --windowed \
  --name 出口IP换向器 --collect-all customtkinter gui.py
```

- `--onefile`：单文件 exe
- `--windowed`：不显示控制台黑框
- `--collect-all customtkinter`：打包主题资源，否则运行时报错
